# Question 5: Software Maintenance, Reengineering, and AI in Software Engineering

## 1. Introduction to Software Maintenance

Software maintenance is the process of modifying, updating, and improving software after it has been delivered to users. It helps to fix errors, improve performance, add new features, and make software compatible with modern technologies.

In the Student Management System, software maintenance is required to improve its speed, remove errors, and provide better functionality.

## 2. Problems in the Existing System

The college's existing Student Management System has the following problems:

1. **Slow Performance:** The system takes more time to load student records and generate reports.
2. **Frequent Errors:** The software produces errors while processing student information.
3. **Outdated Features:** Some features do not meet the current requirements of students and faculty.
4. **Poor User Experience:** The interface may be difficult to use and navigate.
5. **Security Issues:** Older software may contain security weaknesses and outdated protection mechanisms.

## 3. Suitable Types of Software Maintenance

Four types of software maintenance can be applied:

### a) Corrective Maintenance
It involves identifying and fixing errors in the software.

**Application:** Fixing errors in student registration, attendance calculation, and fee payment.

### b) Adaptive Maintenance
It involves modifying software to work with new technologies or environments.

**Application:** Updating the system to support modern browsers, operating systems, and database versions.

### c) Perfective Maintenance
It involves improving the performance and adding new features according to user requirements.

**Application:** Adding online attendance tracking, faster report generation, and a better user interface.

### d) Preventive Maintenance
It involves modifying software to prevent future problems and improve maintainability.

**Application:** Removing unnecessary code, improving documentation, and restructuring the database to prevent future errors.

## 4. Steps Involved in Software Reengineering

Software reengineering is the process of examining, modifying, and restructuring an existing software system to improve its quality without developing a completely new system.

The following steps can be performed:

1. **Inventory Analysis:** Examine the existing system and identify outdated modules and components.
2. **Documentation Analysis:** Study the existing documentation and understand how the system works.
3. **Reverse Engineering:** Analyze the existing code to understand its structure, design, and functionality.
4. **Code Restructuring:** Improve the existing source code by removing duplicate and unnecessary code.
5. **Data Restructuring:** Organize and improve the database to ensure efficient storage and retrieval of student records.
6. **Forward Engineering:** Develop the modernized system with improved features and updated technologies.
7. **Testing:** Test the updated system to ensure that all functions work correctly.

## 5. Two Applications of AI in Software Engineering

Artificial Intelligence can help developers improve software quality and reduce development time.

### a) AI-Based Bug Detection and Code Review

AI-assisted tools can analyze source code, identify programming errors, detect security vulnerabilities, and suggest corrections.

**Example:** GitHub Copilot and SonarQube can assist developers in improving code quality and identifying potential issues.

### b) AI-Based Automated Software Testing

AI can help generate test cases, identify defects, automate repetitive testing tasks, and analyze test results.

**Example:** AI-assisted testing tools can automatically test student registration, attendance management, and fee payment modules to identify errors.

## 6. Three Expected Improvements

After applying software maintenance, reengineering, and AI-assisted techniques, the college can expect the following improvements:

1. **Improved Performance:** Faster processing, quicker database access, and reduced loading time.
2. **Better Software Quality:** Fewer errors, improved security, and increased system reliability.
3. **Enhanced User Experience:** Modern interface, updated features, and easier access for students, teachers, and administrators.
