1. Introduction to DevOps
DevOps is a combination of Development (Dev) and Operations (Ops). It is a software development approach that helps developers and IT teams work together to build, test, and release software quickly and efficiently.

In an online shopping application, DevOps helps developers introduce new features, fix bugs, and deliver updates regularly with fewer errors.
2. Meaning of Continuous Integration and Continuous Delivery/Deployment
Continuous Integration (CI):

Continuous Integration is the process of frequently combining code changes from different developers into a shared repository. Each change is automatically built and tested to identify errors early.

Continuous Delivery (CD):

Continuous Delivery ensures that the tested software is always ready for deployment. The final release is usually approved manually.

Continuous Deployment:

Continuous Deployment automatically releases every successful code change into the production environment without manual approval.
3. CI/CD Pipeline Stages
The main stages of a CI/CD pipeline are:
1. Code: Developers write and upload code to a shared repository like GitHub.
2. Build: The code is compiled and converted into a deployable application.
3. Test: Automated tests check for bugs and errors.
4. Release: The tested application is prepared for deployment.
5. Deploy: The application is automatically deployed to the server.
6. Monitor: The application is monitored to identify errors and performance issues.
4. Explanation of Build, Test and Deployment
Build: The source code is compiled and necessary files are combined to create a working application.

Test: Automated testing checks whether the application works correctly and identifies bugs before release.

Deployment: The tested application is transferred to the production server so that customers can use the latest features.
5. Three Benefits of Automation
1. Saves Time: Automation reduces manual work and speeds up software development and deployment.
2. Reduces Errors: Automated testing identifies bugs and reduces human mistakes.
3. Faster Delivery: New features and bug fixes can be released quickly and regularly.
